CRICKETZONE PWA STARTER

Files: index.html, manifest.webmanifest, sw.js, icon.svg

To let everyone install this as an app, upload all four files to a public HTTPS host (for example GitHub Pages). Open the published HTTPS website on Android Chrome and choose Install app or Add to Home screen.

Important: this package is a starter PWA, not a published website and not a Play Store APK. It does not yet include online accounts, cloud sync, shared match editing, or robust persistent match storage. Those require a backend/database and additional development.
